## What I learned
- Python code goes in a .py file; terminal commands go in the terminal.
- A virtual environment keeps a project's packages separate.
- requirements.txt records package names and versions.
- Git tracks changes to files. GitHub hosts the repository online.
- Cloning creates a connected local copy of a repository.
